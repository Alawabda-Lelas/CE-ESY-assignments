فكرة العمل :
المخزن الدائري يعتمد على مصفوفة ثابتة الحجم مع استخدام مؤشرين :
head :  يشير الى أول عنصر (للقراءة)
tail : يشير الى مكان إضافة عنصر جديد (للكتابة)




وعند الوصول لنهاية المصفوفة يتم الرجوع للبداية باستخدام العملية :
(المؤشر + 1 ) % SIZE
حيث المؤشر هو head أو tail


العمليات المستخدمة :
1.التهيئة:
يتم ضبط المؤشرات (head,tail) والقيمة count الى الصفر

2.الإضافة :
تضيف عنصر جديد الى المخزن 
إذا كان المخزن ممتلئ تظهر رسالة overflow

3.الحذف :
تزيل عنصر من المخزن وتعيده
إذا كان المخزن فارغ تظهر رسالة underflow


في الدالة main :
1.إدخال اسم المستخدم من لوحة المفاتيح 
2.إضافة النص "CE-ESY" الى الاسم
3. تخزين الأحرف داخل المخزن الدائري
4.قراءة الأحرف مرة أخرى من المخزن
5.طباعة الناتج على الشاشة
6.التأكد أن المخزن أصبح فارغاً بعد الانتهاء

حالات الاختبار :
1.عند اختيار حجم مخزن كبير يتم تخزين النص كاملاً
2.عند اختيار حجم مخزن صفير يظهر خطأ overflow لأن المخزن لا يتسع
